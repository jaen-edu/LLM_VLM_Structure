# 학생용 가이드: Windows 11에서 VS Code로 RunPod Pod 접속하기

## 1. 이 가이드의 목적

이 문서는 학교에서 SSH 사용이 허용된 환경을 전제로, Windows 11의 VS Code를 이용해 강사가 준비한 RunPod Pod에 접속하는 방법을 단계별로 설명합니다.

이번 수업에서는 학생마다 서로 다른 Pod가 배정되며, 각자 자기 Pod에 VS Code로 접속해 실습을 진행합니다.

## 2. 먼저 알아야 할 점

> **중요한 점**
> 학교에서 22번 포트를 열어주었더라도, 여러분이 실제로 입력할 RunPod 접속 포트는 22가 아닐 수 있습니다.
> 강사가 알려주는 포트 번호가 가장 중요합니다.

예를 들어, 실제 접속 명령은 아래처럼 보일 수 있습니다.

```bash
ssh root@213.173.108.12 -p 17445
```

여기서 핵심은 다음입니다.

- IP 주소: `213.173.108.12`
- 포트: `17445`
- 사용자명: `root`

즉, 강사가 전달한 정보 그대로 사용하면 됩니다.

## 3. 수업 전에 준비할 것

아래 네 가지를 먼저 준비합니다.

1. Windows 11 PC
2. VS Code 설치
3. `Remote - SSH` 확장 설치
4. SSH 키 생성 후 공개키를 강사에게 제출

## 4. VS Code 설치

VS Code가 설치되어 있지 않다면 먼저 설치합니다.

1. VS Code 설치 페이지에 접속합니다.
2. Windows 버전을 설치합니다.
3. 설치가 끝나면 VS Code를 실행합니다.

## 5. Remote - SSH 확장 설치

1. VS Code를 엽니다.
2. 왼쪽 메뉴에서 Extensions를 선택합니다.
3. 검색창에 `Remote - SSH`를 입력합니다.
4. `ms-vscode-remote.remote-ssh` 확장을 설치합니다.

## 6. Windows에서 SSH 명령 사용 가능 여부 확인

PowerShell을 열고 아래 명령을 실행합니다.

```powershell
ssh -V
```

버전 정보가 보이면 정상입니다.

만약 `ssh` 명령을 찾을 수 없으면 Windows의 `OpenSSH Client`를 추가 설치해야 합니다.

설치 경로 예시:

1. 설정
2. 시스템
3. 선택적 기능
4. 기능 추가
5. `OpenSSH Client` 설치

## 7. SSH 키 생성하기

강사가 여러분의 공개키를 Pod에 미리 등록해야 하므로, 수업 전에 SSH 키를 만들어야 합니다.

PowerShell에서 아래 명령을 실행합니다.

```powershell
ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\id_ed25519" -C "your-name"
```

생성되는 파일은 아래 두 개입니다.

- `id_ed25519`: 개인키
- `id_ed25519.pub`: 공개키

기본값으로 계속 진행해도 됩니다. 비밀번호는 선택 사항입니다.

## 8. 공개키를 강사에게 제출하기

PowerShell에서 아래 명령으로 공개키를 확인합니다.

```powershell
Get-Content "$env:USERPROFILE\.ssh\id_ed25519.pub"
```

출력 예시:

```text
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIExampleKeyGoesHere your-name
```

이 한 줄 전체를 강사에게 제출합니다.

중요:

1. 제출하는 것은 `.pub` 파일 내용입니다.
2. 개인키 파일은 절대 공유하면 안 됩니다.

## 9. 수업 시간에 강사에게 받아야 하는 정보

강사는 여러분에게 아래 정보를 전달합니다.

- Pod 이름 또는 번호
- 공인 IP 주소
- 외부 SSH 포트
- 사용자명 `root`
- 원격 작업 폴더 `/workspace`

예시:

- Pod 이름: `rp-class-07`
- IP: `213.173.108.12`
- Port: `17445`
- User: `root`
- Folder: `/workspace`

## 10. 먼저 네트워크 연결을 확인하기

가장 먼저 해야 할 것은 **강사가 알려준 실제 포트**가 열리는지 확인하는 것입니다.

PowerShell에서 아래 명령을 실행합니다.

```powershell
Test-NetConnection 213.173.108.12 -Port 17445
```

결과에서 `TcpTestSucceeded : True`가 보이면 다음 단계로 진행합니다.

`False`가 나오면 바로 강사에게 알립니다.

## 11. 가능하면 터미널 SSH도 먼저 시험하기

VS Code에 들어가기 전에 터미널 접속이 되는지 먼저 보는 것이 문제를 빨리 찾는 데 도움이 됩니다.

아래 명령을 실행합니다.

```powershell
ssh root@213.173.108.12 -p 17445
```

처음 접속이면 신뢰 여부를 묻는 메시지가 나올 수 있습니다. 본인이 받은 Pod가 맞다면 `yes`를 입력합니다.

터미널 접속이 된다면 VS Code도 연결될 가능성이 높습니다.

## 12. VS Code에 SSH Host 등록하기

가장 쉬운 방법은 VS Code 명령 팔레트로 SSH Host를 추가하는 것입니다.

1. VS Code에서 `Ctrl+Shift+P`를 누릅니다.
2. `Remote-SSH: Add New SSH Host...`를 선택합니다.
3. 아래 형식으로 입력합니다.

```text
ssh root@213.173.108.12 -p 17445
```

4. 저장할 SSH 설정 파일을 선택합니다.
5. 보통 기본 사용자 SSH 설정 파일을 선택하면 됩니다.

개인키 경로를 명시하고 싶다면 아래처럼 입력해도 됩니다.

```text
ssh root@213.173.108.12 -p 17445 -i ~/.ssh/id_ed25519
```

## 13. 직접 SSH 설정 파일을 편집하는 방법

필요하면 아래 파일을 직접 열어 추가할 수 있습니다.

경로:

```text
%USERPROFILE%\.ssh\config
```

예시:

```ssh-config
Host rp-class-07
    HostName 213.173.108.12
    User root
    Port 17445
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60
```

이렇게 저장하면 다음부터는 `rp-class-07`만 선택해서 접속할 수 있습니다.

## 14. VS Code로 Pod에 접속하기

1. `Ctrl+Shift+P`를 누릅니다.
2. `Remote-SSH: Connect to Host...`를 선택합니다.
3. 방금 추가한 Host를 선택합니다.
4. 플랫폼을 묻는 창이 뜨면 `Linux`를 선택합니다.
5. 잠시 기다리면 새 VS Code 창이 열립니다.

## 15. 원격 폴더 열기

연결 후에는 원격 폴더를 열어야 합니다.

1. `File > Open Folder...`를 선택합니다.
2. `/workspace`를 입력하거나 선택합니다.
3. 확인을 누릅니다.

실습 파일은 가능하면 `/workspace` 아래에 저장합니다.

이유:

- `/workspace`는 보통 영구 저장 영역입니다.
- `/tmp`는 Pod 중지 시 사라질 수 있습니다.

## 16. 접속 직후 확인할 것

VS Code 하단 왼쪽에 원격 연결 표시가 있으면 정상입니다.

터미널을 열고 아래 명령을 실행해 봅니다.

```bash
pwd
ls
nvidia-smi
```

`nvidia-smi`가 나오면 GPU Pod에 정상 연결된 것입니다.

## 17. 실습 중 지켜야 할 것

1. 강사 지시 없이 Pod를 중지하거나 재시작하지 않습니다.
2. 파일은 `/workspace`에 저장합니다.
3. 접속 정보는 다른 학생과 섞지 않습니다.
4. 접속이 끊기면 포트가 바뀌었는지 먼저 강사에게 확인합니다.

## 18. 웹 서비스 포트 사용하기

원격 Pod에서 웹 앱이나 노트북 서버를 띄우면 VS Code가 포트 포워딩을 도와줄 수 있습니다.

예를 들어 아래와 같이 실행했다면:

```bash
python -m http.server 8000
```

VS Code가 8000 포트를 감지하고 로컬로 열어 줄 수 있습니다.

직접 열려면 아래 순서로 진행합니다.

1. `Ctrl+Shift+P`
2. `Ports: Forward a Port`
3. 원격 포트 번호 입력

## 19. 자주 생기는 문제와 해결 방법

### 문제 1. `Permission denied (publickey)`가 나온다

의미:

- 공개키가 Pod에 반영되지 않았거나
- 내 PC가 다른 개인키를 사용하고 있다는 뜻입니다.

해결:

1. 공개키를 강사에게 제대로 제출했는지 확인합니다.
2. `.pub` 파일의 한 줄 전체를 보냈는지 확인합니다.
3. SSH 설정의 `IdentityFile` 경로가 맞는지 확인합니다.
4. 강사에게 Pod에 공개키가 들어갔는지 확인 요청합니다.

### 문제 2. `Test-NetConnection`은 실패하고 SSH도 안 된다

의미:

- 네트워크 레벨에서 아직 접속이 안 되는 상태입니다.

해결:

1. IP와 포트를 정확히 입력했는지 확인합니다.
2. Pod가 완전히 올라왔는지 강사에게 확인합니다.
3. 학교가 22번은 열었지만 실제 외부 포트는 허용하지 않았을 가능성도 있으니 강사에게 알립니다.

### 문제 3. 호스트 키 경고가 뜬다

Pod 재배포나 재시작 후에는 호스트 키가 바뀔 수 있습니다.

PowerShell에서 아래 명령을 실행합니다.

```powershell
ssh-keygen -R [213.173.108.12]:17445
```

그다음 다시 접속합니다.

### 문제 4. VS Code가 연결 중 멈춘다

해결 순서:

1. 먼저 `Test-NetConnection`으로 실제 포트가 열리는지 확인합니다.
2. 터미널 `ssh` 접속이 되는지 확인합니다.
3. 그래도 안 되면 강사에게 Pod 상태를 확인해 달라고 요청합니다.

### 문제 5. 비밀번호를 묻는다

이번 수업은 기본적으로 공개키 방식입니다. 보통 비밀번호를 묻지 않아야 정상입니다.

해결:

1. 임의의 비밀번호를 반복 입력하지 않습니다.
2. 강사에게 공개키 등록 상태를 확인해 달라고 요청합니다.
3. 강사가 별도로 비밀번호 방식을 공지한 경우에만 전달받은 비밀번호를 사용합니다.

### 문제 6. VS Code Server 설치가 꼬인 것 같다

강사 안내에 따라 아래 폴더를 삭제하고 다시 접속할 수 있습니다.

```bash
rm -rf ~/.vscode-server
```

## 20. 빠른 접속 요약

1. VS Code 설치
2. `Remote - SSH` 설치
3. PowerShell에서 SSH 키 생성
4. 공개키를 강사에게 제출
5. 강사가 준 `IP + 포트 + 사용자명`으로 SSH Host 추가
6. `Remote-SSH: Connect to Host` 실행
7. `/workspace` 열기

## 21. 끝까지 안 되면 무엇을 확인해야 하나

아래 세 가지를 순서대로 보면 대부분 원인을 찾을 수 있습니다.

1. 공개키를 강사에게 제대로 제출했는가
2. 강사가 준 IP와 포트를 정확히 입력했는가
3. `Test-NetConnection` 결과가 `True`인가

세 가지가 모두 맞는데도 접속이 안 되면, 네트워크 또는 Pod 상태 문제일 가능성이 큽니다. 이 경우 바로 강사에게 알려 예비 Pod로 전환하는 것이 가장 빠릅니다.
